# Застосунок учителя (Electron)

Замінює ручний запуск `start-server.ps1` + `start-mic.ps1`: відкрив програму — натиснув
«Почати урок» — звук іде. Клас і мікрофон запам'ятовуються.

```powershell
cd app
npm install
npm start          # запуск для розробки
npm run dist       # інсталятор і portable .exe у app/dist (потрібні server/bin/*.exe)
```

Що робить сам: роздає сторінку для дітей (без Python і прав адміністратора), запускає
MediaMTX і ffmpeg, один раз відкриває порти у фаєрволі (одне вікно UAC), показує QR-код,
лічильник слухачів і рівень голосу, перепідключає мікрофон, не дає ПК заснути.
Опція «Починати урок одразу після відкриття» — урок стартує без жодного кліку.

## Клас: імʼя, чат, слово

- Перед тим як слухати, учень вводить імʼя (2–20 символів: літери, цифри, пробіл, дефіс, апостроф).
  Вчитель бачить список учнів і хто з них слухає.
- Чат «питання → відповідь»: учень бачить лише свої питання й відповіді вчителя. Чат можна вимкнути.
- Режим рації: вчитель натискає «Дати слово» — учень вмикає мікрофон, і вчитель чує його наживо,
  паралельно з уроком (WebRTC, без запису). «Забрати слово» вимикає мікрофон учня.
- «Вигнати» (два натискання) відключає учня від звуку і чату; за потреби його можна «повернути».
  Блокування діє на ідентифікатор сторінки і на IP телефона, до кінця уроку.
- Мікрофон у браузері працює тільки на HTTPS, тому для голосу є друга адреса `https://<IP>:8443/`
  із самопідписаним сертифікатом: телефон один раз покаже попередження («Додатково» → «Все одно
  перейти»). Слухання і чат працюють і на звичайній HTTP-адресі.
- Кнопка мікрофона (перекреслена, коли вимкнено) вимикає звук без розриву звʼязку зі слухачами. «Завершити урок» потребує другого кліку.
- Порт 8443/tcp відкривається тим самим одноразовим вікном UAC (скрипт `server/win/allow-firewall.ps1`).
