# Застосунок учителя (Electron)

Замінює ручний запуск `start-server.ps1` + `start-mic.ps1`: відкрив програму — натиснув
«Почати урок» — звук іде. Клас і мікрофон запам'ятовуються.

```powershell
cd app
npm install
npm start          # запуск для розробки
npm run dist       # інсталятор і portable .exe у app/dist (потрібні server/bin/*.exe)
```

Що робить сам: роздає сторінку для дітей (без Python і прав адміністратора), запускає
MediaMTX і ffmpeg, один раз відкриває порти у фаєрволі (одне вікно UAC), показує QR-код,
лічильник слухачів і рівень голосу, перепідключає мікрофон, не дає ПК заснути.
Опція «Починати урок одразу після відкриття» — урок стартує без жодного кліку.
