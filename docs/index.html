Lessons in Shelter

Звук уроку в навушниках кожної дитини

Учитель говорить у петличний мікрофон — голос іде в навушники всього класу. Без інтернету, без застосунку, без реєстрації. Сервер стоїть тут же, в укритті.

01Навіщо це

Коли клас спускається в укриття, урок не зникає — зникає можливість його почути. У підвалі гучно, голоси з сусідніх секторів накладаються, діти в дальньому кутку не чують нічого. Просити вчителя говорити голосніше — не вихід: за годину голос сідає.

Ідея така сама, як у хмарного сервісу OpenedMic, але з однією принциповою відмінністю: сервер стоїть тут же, в укритті. Немає інтернету, немає зв'язку, немає світла в місті — звук усе одно є.

02Як це працює

петличка ──► [ сервер: Pi / ноутбук ] ──► [ Wi-Fi точка доступу ] ffmpeg → MediaMTX мережа "Ukryttia-279" Opus, ~48 кбіт/с │ ┌───────────┼───────────┐ телефон телефон телефон http://10.0.0.1:8080/listen.html?ch=klas-5-1

Мікрофон вмикається в сервер, а не в телефон учителя — браузери не дають доступ до мікрофона на сторінках без HTTPS. Учителю власний телефон взагалі не потрібен.

Один голосовий канал — близько 48 кбіт/с. На 40 дітей виходить менше 2 Мбіт/с, тож вузьке місце не швидкість, а кількість підключень до точки доступу.

04Встановлення на чистий Windows

Інструкція для комп'ютера, на якому немає нічого, крім щойно встановленої Windows 10 або 11. Ані Python, ані Node, ані Git ставити не доведеться. Разом — близько 20 хвилин, з яких більшість припадає на завантаження.

Інтернет потрібен лише на час встановлення. Під час уроку ані сервер, ані телефони в ньому не потребують.

  1. Покласти проєкт на комп'ютер

    На сторінці проєкту в GitHub: зелена кнопка Code → Download ZIP. Розпакувати, наприклад, у C:\lessonsinshelter.

  2. Дозволити запуск скриптів

    Windows не запускає скрипти PowerShell за замовчуванням, а файли з інтернету позначає як небезпечні. Відкрийте PowerShell («Пуск» → наберіть powershell): 

    cd C:\lessonsinshelter
Get-ChildItem -Recurse | Unblock-File
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

    На запит підтвердження — Y і Enter. Робиться один раз.

  3. Завантажити дві програми

    .\server\win\download-tools.ps1

    Скрипт сам завантажить mediamtx.exe (медіасервер) і ffmpeg.exe (робота зі звуком) у папку server\bin. Разом близько 140 МБ.

  4. Дізнатися назву мікрофона

    Увімкніть петличку в USB і виконайте:

    .\server\win\list-devices.ps1

    Знайдіть свій мікрофон і скопіюйте назву цілком, разом із дужками — наприклад Мікрофон (USB Audio Device).

  5. Відкрити порти у фаєрволі

    Потрібен PowerShell від імені адміністратора: «Пуск» → правою кнопкою по Windows PowerShell → «Запуск від імені адміністратора». 

    cd C:\lessonsinshelter
.\server\win\allow-firewall.ps1

    Робиться один раз. Без цього телефони не побачать сервер, навіть підключені до того ж Wi-Fi.

  6. Запустити сервер

    .\server\win\start-server.ps1

    Скрипт надрукує адреси, за якими телефони відкриють сторінку. Це вікно має лишатися відкритим.

    Якщо Python на комп'ютері немає — а на чистій Windows його немає — сторінку роздає вбудований вебсервер Windows, і тоді це вікно теж має бути відкрите від імені адміністратора. Скрипт сам про це скаже і зупиниться, якщо прав не вистачає.

  7. Увімкнути мікрофон

    Відкрийте друге вікно PowerShell, перше не чіпайте:

    cd C:\lessonsinshelter
.\server\win\start-mic.ps1 -Device "Мікрофон (USB Audio Device)" -Channel klas-5-1 -Slow

    Ключ -Slow вмикає резервний потік для айфонів — лишайте його завжди.

Перевірка перед першим уроком Спершу відкрийте адресу на самому комп'ютері — якщо тут не працює, справа не в телефонах. Потім на одному Android і обов'язково на одному iPhone. І тільки тоді — на цілому класі.

05Щоденний запуск

Після встановлення потрібні лише два вікна PowerShell:

# вікно 1 — сервер і сторінка
cd C:\lessonsinshelter
.\server\win\start-server.ps1

# вікно 2 — мікрофон
cd C:\lessonsinshelter
.\server\win\start-mic.ps1 -Device "Мікрофон (USB Audio Device)" -Channel klas-5-1 -Slow

Обидва вікна мають лишатися відкритими до кінця уроку.

06Як підключаються діти

  1. Телефон підключається до тієї самої Wi-Fi мережі, що й сервер.
  2. У браузері відкриває адресу, яку надрукував сервер — наприклад http://192.168.0.50:8080/
  3. Обирає свій клас у списку.
  4. Натискає велику кнопку Слухати.

Нічого встановлювати, реєструватись і вводити паролі не потрібно. Щоб не диктувати адресу кожному, роздрукуйте web/print.html і повісьте аркуш на стіну.

На сторінці класу внизу є пряме посилання саме на цей клас — з кнопкою «Копіювати». Його можна кинути в чат класу, і дитина потрапить одразу на свій урок, минаючи список. Виглядає воно так: 

http://192.168.0.50:8080/listen.html?ch=klas-5-1

07Що знати вчителю

Мікрофон чує вас, а не клас

Питання з місця сусіди почують так само, як завжди, — а от у навушниках його майже не буде. Якщо питання важливе, коротко повторіть його вголос, перш ніж відповідати. Це та сама звичка, що й на будь-якій конференції з мікрофоном.

Петличка — на долоню нижче підборіддя

Система сама вирівнює гучність: якщо ви на мить відвернулись або підвищили голос, у навушниках це залишиться рівним.

Телефон може «загубити» мережу

Android іноді сам перемикається на мобільний інтернет, бо в нашій мережі інтернету немає. Дитині треба один раз обрати «Залишатися підключеним».

Екран краще не гасити

На частині телефонів, особливо на айфонах, звук може зупинитись після блокування екрана. Сторінка сама просить екран не вимикати.

Айфони капризніші

Safari суворіший до сторінок без HTTPS. Якщо на айфоні тиша — на сторінці є кнопка «Спробувати повільний режим». Звук піде, але з відставанням у кілька секунд, тож дитині краще дивитись у зошит, а не на губи вчителя.

08Кілька класів одночасно

В одному укритті можуть паралельно йти кілька уроків — кожен клас має власний канал і власний мікрофон. Список редагується у файлі web/channels.json: 

{ "id": "klas-5-1", "name": "5-1", "room": "Сектор 1", "color": "#e0b341" }

Для кожного каналу запускається свій start-mic зі своїм мікрофоном.

Рознесіть класи по кутах Якщо два сектори поруч, дитина може випадково обрати сусідній урок і слухати чужу тему, не розуміючи, чому нічого не сходиться.

09Якщо щось не працює

ОзнакаПричина і що робити
Сторінка пише «Server is up and running» або щось чуже Порт 8080 зайнятий іншою програмою (pgAdmin, Jenkins). Запустіть на іншому порту: allow-firewall.ps1 -WebPort 8081 від адміністратора, потім start-server.ps1 -WebPort 8081, і давайте телефонам адресу з :8081
«Немає зв'язку з сервером» на телефоніТелефон у чужій мережі, або не виконано крок 5

10Raspberry Pi як постійна коробка

./server/linux/install.sh                        # один раз, поки ще є інтернет
./server/linux/start-server.sh                   # медіасервер + сторінка
SLOW=1 ./server/linux/start-mic.sh plughw:1,0 klas-5-1

Щоб усе піднімалось саме при ввімкненні живлення:

sudo cp server/linux/systemd/*.service /etc/systemd/system/
sudo systemctl enable --now lessons-server lessons-web lessons-mic@klas-5-1
Що ще не перевірено наживо Увесь тракт прогнано на машині розробки: сервер приймає звук, віддає його по WebRTC, резервний HLS-потік для Safari теж віддається. Не перевірено відтворення в реальному браузері телефона — це перший пункт пілотного тесту, і починати треба саме з айфона.
Сторінка для дітей написана на чистому HTML, CSS і JS — жодних CDN, Tailwind чи зовнішніх шрифтів: усе, що вантажиться ззовні, в укритті без інтернету просто не завантажиться. Ця сторінка зроблена за тим самим правилом.
