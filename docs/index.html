Lessons in Shelter

Звук уроку в навушниках кожної дитини

Учитель говорить у петличний мікрофон — голос іде в навушники всього класу. Без інтернету, без застосунку, без реєстрації. Сервер стоїть тут же, в укритті.

01Навіщо це

Коли клас спускається в укриття, урок не зникає — зникає можливість його почути. У підвалі гучно, голоси з сусідніх секторів накладаються, діти в дальньому кутку не чують нічого. Просити вчителя говорити голосніше — не вихід: за годину голос сідає.

Ідея така сама, як у хмарного сервісу OpenedMic, але з однією принциповою відмінністю: сервер стоїть тут же, в укритті. Немає інтернету, немає зв'язку, немає світла в місті — звук усе одно є.

02Як це працює

петличка ──► [ сервер: Pi / ноутбук ] ──► [ Wi-Fi точка доступу ] ffmpeg → MediaMTX мережа "Ukryttia-279" Opus, ~48 кбіт/с │ ┌───────────┼───────────┐ телефон телефон телефон http://10.0.0.1:8080/listen.html?ch=klas-5-1

Мікрофон вмикається в сервер, а не в телефон учителя — браузери не дають доступ до мікрофона на сторінках без HTTPS. Учителю власний телефон взагалі не потрібен.

Один голосовий канал — близько 48 кбіт/с. На 40 дітей виходить менше 2 Мбіт/с, тож вузьке місце не швидкість, а кількість підключень до точки доступу.

04Встановлення на Windows — з нуля

Інструкція для людини, яка ніколи не налаштовувала комп'ютер. Розписано кожне натискання: куди клацнути, що вставити і що має з'явитися на екрані. Разом — близько 20 хвилин, робиться один раз.

Інтернет потрібен лише на час встановлення. Під час уроку ані комп'ютер, ані телефони в ньому не потребують.

Як читати Жирним — кнопки й пункти меню. Темні блоки — команди: їх не набирають вручну, а копіюють і вставляють. Після кожного кроку є «Вийшло, якщо» — не йдіть далі, поки не побачите саме це.

Три вміння, які знадобляться

1. Скопіювати команду Затисніть ліву кнопку миші на початку команди, протягніть до кінця, натисніть Ctrl + C.
2. Вставити і виконати Клацніть правою кнопкою всередині вікна PowerShell — команда вставиться. Потім натисніть Enter.
3. Дочекатися кінця Команда виконалась, коли знову з'явився рядок PS C:\lessonsinshelter> з блимаючим курсором. До того — чекайте.
Частина 1 · Встановлення · один раз

  1. Завантажити проєкт

    1. Відкрийте сторінку проєкту на GitHub у браузері.
    2. Натисніть зелену кнопку <> Code над списком файлів.
    3. У меню, що випало, натисніть Download ZIP.

    У папці Завантаження з'явився файл lessonsinshelter-main.zip. Відкрити цю папку: Win + E → ліворуч Завантаження.

  2. Розпакувати в правильне місце

    1. Клацніть правою кнопкою по файлу lessonsinshelter-main.zip → Видобути все...
    2. У полі зі шляхом зітріть усе і впишіть C:\ → Видобути.
    3. На диску C: знайдіть папку lessonsinshelter-main, клацніть правою кнопкою → Перейменувати → зітріть -main → Enter. Якщо Windows питає дозвіл — Продовжити.

    У папці C:\lessonsinshelter лежать папки docs, server, web і файл README.md.

    Якщо там ще одна папка lessonsinshelter-main — перенесіть її вміст на рівень вище (Ctrl+A, Ctrl+X, перейти вище, Ctrl+V).

  3. Відкрити PowerShell від імені адміністратора

    Усі команди вводяться сюди. Щоб не плутатись, завжди відкривайте його саме так.

    1. Натисніть Пуск і, нічого не клацаючи, наберіть powershell.
    2. Клацніть правою кнопкою по Windows PowerShell → Запуск від імені адміністратора.
    3. На питання «Дозволити цій програмі вносити зміни?» — Так.
    4. Вставте й виконайте:
    cd C:\lessonsinshelter

    У заголовку вікна є слово Адміністратор, а рядок виглядає як PS C:\lessonsinshelter>.

    «Не удается найти путь» — папка розпакована не туди. Поверніться до кроку 2.

  4. Дозволити запуск скриптів

    У тому самому вікні виконайте по черзі дві команди:

    Get-ChildItem -Recurse | Unblock-File
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

    На питання «Ви впевнені?» надрукуйте Y і натисніть Enter.

    Знову з'явився рядок PS C:\lessonsinshelter>, червоного тексту немає.

  5. Завантажити дві програми

    Потрібен інтернет. Скрипт сам завантажить MediaMTX і ffmpeg — близько 140 МБ, 2–10 хвилин.

    .\server\win\download-tools.ps1

    Зеленим написано Готово: mediamtx.exe і Готово: ffmpeg.exe.

    Помилка з'єднання — перевірте інтернет і запустіть ту саму команду ще раз.

  6. Відкрити доступ для телефонів

    Фаєрвол Windows не пускає до комп'ютера чужі пристрої. Робимо «дверцята» для нашої системи:

    .\server\win\allow-firewall.ps1

    Зеленим — чотири рядки, що починаються з Відкрито:.

    Далі підключіть комп'ютер до Wi-Fi для дітей і позначте мережу як приватну: Пуск → Параметри → Мережа й Інтернет → Властивості мережі → Профіль мережі: Приватна.

  7. Дізнатися назву мікрофона

    Вставте петличку в USB, зачекайте 10 секунд і виконайте:

    .\server\win\list-devices.ps1

    Знайдіть рядок, що закінчується на (audio):

    [dshow @ 0000020f] "Мікрофон (USB Audio Device)" (audio)

    Назва — те, що між лапками. Запишіть її літера в літеру, разом із дужками. Скопіювати з вікна: виділіть мишкою і натисніть Enter.

    Кілька рядків з (audio) — беріть той, де є USB або назва петлички. «Realtek» — це вбудований мікрофон ноутбука.

Встановлення закінчено. Кроки 1–7 більше не потрібні — хіба що зміните мікрофон, тоді повторіть крок 7.

05Запуск перед уроком

Щоразу потрібні два вікна PowerShell одночасно: одне роздає сторінку і звук, друге бере звук з мікрофона. Обидва не закривати до кінця уроку — лише згортати.

Частина 2 · Щоразу · ~2 хвилини

  1. Вікно 1 — сервер

    1. Підключіть комп'ютер до шкільного Wi-Fi.
    2. Відкрийте PowerShell від імені адміністратора (як у кроці 3) і виконайте:
    cd C:\lessonsinshelter
.\server\win\start-server.ps1

    Якщо вискочить «Брандмауер Windows заблокував деякі функції» — галочка Приватні мережі → Дозволити доступ.

    Зеленим Медіасервер працює, а нижче — адреса для дітей, наприклад http://192.168.0.50:8080/. Запишіть її. Рядок PS> тут не з'являється — так і має бути.

  2. Вікно 2 — мікрофон

    1. Перше вікно не чіпайте. Відкрийте ще одне PowerShell від імені адміністратора.
    2. Скопіюйте команду нижче спершу в Блокнот.
    3. Замініть Мікрофон (USB Audio Device) на назву з кроку 7 (лапки лишаються), а klas-5-1 — на код свого класу.
    4. Скопіюйте виправлене з Блокнота у вікно 2 і натисніть Enter.
    cd C:\lessonsinshelter
.\server\win\start-mic.ps1 -Device "Мікрофон (USB Audio Device)" -Channel klas-5-1 -Slow

    Коди класів: klas-5-1, klas-5-2, klas-6, klas-7-1, klas-7-2, klas-8, klas-9-1, klas-9-2, klas-10, klas-11 (список — у web/channels.json). -Slow не прибирайте: він потрібен для айфонів.

    Написано клас, мікрофон і пряме посилання на цей клас. Після цього вікно «застигає» — це нормально.

    Жовте «Каналу ... немає» — помилка в коді класу. Could not find audio only device — неточна назва мікрофона.

    Збережіть файл Блокнота на робочому столі як мікрофон.txt — завтра просто скопіюєте звідти.

Перевірка перед першим уроком — за день, не при дітях 1) Адреса на самому комп'ютері — має відкритися список класів. 2) Один Android: «Слухати», говоріть у петличку — чуєте себе в навушниках. 3) Обов'язково один iPhone; якщо тиша — «Спробувати повільний режим» і 5–10 секунд. 4) Тільки тоді — цілий клас.

Як вимкнути

У вікні 2, потім у вікні 1: клацнути всередину → Ctrl + C → закрити вікно. Якщо закрити просто хрестиком, наступного разу може з'явитися «порт зайнятий» — див. «Якщо щось не працює».

06Як підключаються діти

  1. Телефон підключається до тієї самої Wi-Fi мережі, що й сервер.
  2. У браузері відкриває адресу, яку надрукував сервер — наприклад http://192.168.0.50:8080/
  3. Обирає свій клас у списку.
  4. Натискає велику кнопку Слухати.

Нічого встановлювати, реєструватись і вводити паролі не потрібно. Щоб не диктувати адресу кожному, роздрукуйте web/print.html і повісьте аркуш на стіну.

На сторінці класу внизу є пряме посилання саме на цей клас — з кнопкою «Копіювати». Його можна кинути в чат класу, і дитина потрапить одразу на свій урок, минаючи список. Виглядає воно так: 

http://192.168.0.50:8080/listen.html?ch=klas-5-1

07Що знати вчителю

Мікрофон чує вас, а не клас

Питання з місця сусіди почують так само, як завжди, — а от у навушниках його майже не буде. Якщо питання важливе, коротко повторіть його вголос, перш ніж відповідати. Це та сама звичка, що й на будь-якій конференції з мікрофоном.

Петличка — на долоню нижче підборіддя

Система сама вирівнює гучність: якщо ви на мить відвернулись або підвищили голос, у навушниках це залишиться рівним.

Телефон може «загубити» мережу

Android іноді сам перемикається на мобільний інтернет, бо в нашій мережі інтернету немає. Дитині треба один раз обрати «Залишатися підключеним».

Екран краще не гасити

На частині телефонів, особливо на айфонах, звук може зупинитись після блокування екрана. Сторінка сама просить екран не вимикати.

Айфони капризніші

Safari суворіший до сторінок без HTTPS. Якщо на айфоні тиша — на сторінці є кнопка «Спробувати повільний режим». Звук піде, але з відставанням у кілька секунд, тож дитині краще дивитись у зошит, а не на губи вчителя.

08Кілька класів одночасно

В одному укритті можуть паралельно йти кілька уроків — кожен клас має власний канал і власний мікрофон. Список редагується у файлі web/channels.json: 

{ "id": "klas-5-1", "name": "5-1", "room": "Сектор 1", "color": "#e0b341" }

Для кожного каналу запускається свій start-mic зі своїм мікрофоном.

Рознесіть класи по кутах Якщо два сектори поруч, дитина може випадково обрати сусідній урок і слухати чужу тему, не розуміючи, чому нічого не сходиться.

10Raspberry Pi як постійна коробка

./server/linux/install.sh                        # один раз, поки ще є інтернет
./server/linux/start-server.sh                   # медіасервер + сторінка
SLOW=1 ./server/linux/start-mic.sh plughw:1,0 klas-5-1

Щоб усе піднімалось саме при ввімкненні живлення:

sudo cp server/linux/systemd/*.service /etc/systemd/system/
sudo systemctl enable --now lessons-server lessons-web lessons-mic@klas-5-1
Що ще не перевірено наживо Увесь тракт прогнано на машині розробки: сервер приймає звук, віддає його по WebRTC, резервний HLS-потік для Safari теж віддається. Не перевірено відтворення в реальному браузері телефона — це перший пункт пілотного тесту, і починати треба саме з айфона.
Сторінка для дітей написана на чистому HTML, CSS і JS — жодних CDN, Tailwind чи зовнішніх шрифтів: усе, що вантажиться ззовні, в укритті без інтернету просто не завантажиться. Ця сторінка зроблена за тим самим правилом.
