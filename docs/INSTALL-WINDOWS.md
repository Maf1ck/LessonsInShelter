# Встановлення на Windows — покроково, з нуля

Ця інструкція для людини, яка **ніколи не налаштовувала комп'ютер**. Тут розписано кожне
натискання: куди клацнути, що набрати і що має з'явитися на екрані. Спеціальні знання не
потрібні. Треба лише уважно робити крок за кроком і не пропускати.

> **Як читати цю інструкцію**
> - **Жирним** позначено кнопки й пункти меню, які треба натиснути.
> - Сірі блоки з текстом — це **команди**. Їх не треба набирати вручну: скопіюйте і вставте
>   (як — пояснено в розділі «Три вміння, які знадобляться»).
> - Після кожного кроку є пункт **«Як зрозуміти, що вийшло»**. Не переходьте далі, поки не
>   побачите саме це.

## Перед початком

### Що має бути під рукою

| Що | Навіщо |
|---|---|
| Ноутбук або комп'ютер з Windows 10 чи 11 | на ньому працюватиме сервер |
| USB-мікрофон-петличка (або USB-звукова карта з мікрофоном) | через нього звучить голос учителя |
| Wi-Fi роутер або точка доступу | до цієї мережі підключаться телефони дітей |
| **Інтернет** — лише на час встановлення | щоб завантажити програми. Під час уроку інтернет не потрібен |
| Павербанк або ДБЖ | щоб усе працювало, коли зникне світло |

### Кілька слів, які трапляться в тексті

| Слово | Що це означає |
|---|---|
| **Папка** | те саме, що «тека» — місце на комп'ютері, де лежать файли |
| **PowerShell** | вікно, куди вписують команди для комп'ютера. Виглядає як синій або чорний прямокутник із текстом. Воно вже є в кожній Windows |
| **Команда** | рядок тексту, який ви вставляєте в PowerShell і натискаєте Enter |
| **Enter** | велика клавіша праворуч на клавіатурі, іноді зі стрілкою ↵ |
| **Від імені адміністратора** | особливий спосіб відкрити програму, коли їй дозволено змінювати налаштування Windows |

## Три вміння, які знадобляться

### 1. Скопіювати команду з цієї інструкції

1. Наведіть мишку на початок команди в сірому блоці.
2. Затисніть **ліву кнопку миші** і протягніть до кінця команди — текст підсвітиться.
3. Натисніть на клавіатурі **Ctrl + C** (затисніть Ctrl і, не відпускаючи, натисніть C).

> На GitHub у правому верхньому куті сірого блоку є маленька кнопка з двома квадратиками —
> вона копіює всю команду одним клацанням.

### 2. Вставити команду в PowerShell і виконати

1. Клацніть мишкою всередині вікна PowerShell.
2. Натисніть **правою кнопкою миші** в будь-якому місці вікна — команда вставиться сама.
   (Можна також натиснути **Ctrl + V**.)
3. Натисніть **Enter**.

### 3. Зрозуміти, що команда закінчилась

Коли команда виконалась, у вікні знову з'являється рядок, який закінчується знаком `>`,
і за ним блимає курсор. Наприклад:

```
PS C:\lessonsinshelter>
```

Це означає «готово, можна вводити наступну команду». Поки цього рядка немає — **чекайте**
і нічого не натискайте.

> ⚠️ Якщо вставили кілька рядків одразу, PowerShell виконає їх по черзі сам. Це нормально.

## Крок 1. Завантажити проєкт

**Що зробити:**

1. Відкрийте браузер (Chrome, Edge — будь-який).
2. Перейдіть на сторінку проєкту на GitHub (посилання вам дав той, хто порадив цю систему).
3. Знайдіть зелену кнопку **`<> Code`** праворуч над списком файлів і натисніть її.
4. У меню, що випало, натисніть **Download ZIP** (в самому низу).

**Як зрозуміти, що вийшло:** у папці **Завантаження** з'явився файл з назвою на кшталт
`lessonsinshelter-main.zip`.

> Щоб відкрити папку «Завантаження»: натисніть на клавіатурі **Win + E** (клавіша з
> віконцем Windows і літера E) → ліворуч клацніть **Завантаження**.

---

## Крок 2. Розпакувати його в правильне місце

Файл `.zip` — це «запакована коробка». Її треба розпакувати, і саме в певне місце, бо всі
команди нижче розраховані на папку `C:\lessonsinshelter`.

**Що зробити:**

1. У папці **Завантаження** клацніть **правою кнопкою** по файлу `lessonsinshelter-main.zip`.
2. Оберіть **Видобути все...** (або **Извлечь все...** / **Extract All...**, якщо Windows
   іншою мовою).
3. У віконці, що відкрилося, зітріть шлях у полі і впишіть:
   ```
   C:\
   ```
4. Натисніть **Видобути**.
5. Відкриється диск `C:`. Серед папок знайдіть **lessonsinshelter-main**.
6. Клацніть по ній **правою кнопкою** → **Перейменувати** → зітріть `-main`, щоб лишилось
   рівно `lessonsinshelter` → натисніть **Enter**.
7. Якщо Windows питає дозвіл (з'явиться віконце з кнопкою **Продовжити**) — натисніть
   **Продовжити**.

**Як зрозуміти, що вийшло:** відкрийте папку `C:\lessonsinshelter`. Всередині мають бути
папки **docs**, **server**, **web** і файл **README.md**.

> ❗ Якщо всередині є ще одна папка `lessonsinshelter-main`, а вже в ній `docs`, `server`,
> `web` — значить, розпакувалось «на поверх глибше». Відкрийте внутрішню папку, виділіть
> усе (**Ctrl + A**), виріжте (**Ctrl + X**), поверніться в `C:\lessonsinshelter` і вставте
> (**Ctrl + V**). Порожню внутрішню папку видаліть.

## Крок 3. Відкрити PowerShell від імені адміністратора

Усі команди в цій інструкції вводяться в PowerShell. Щоб не плутатись, **завжди відкривайте
його саме так** — від імені адміністратора.

**Що зробити:**

1. Натисніть кнопку **Пуск** (значок Windows у лівому нижньому куті екрана).
2. Одразу, нічого не клацаючи, наберіть на клавіатурі слово:
   ```
   powershell
   ```
3. У результатах пошуку з'явиться **Windows PowerShell**. Клацніть по ньому **правою
   кнопкою миші**.
4. Оберіть **Запуск від імені адміністратора**.
5. З'явиться віконце «Дозволити цій програмі вносити зміни на вашому пристрої?» — натисніть
   **Так**.

**Як зрозуміти, що вийшло:** відкрилось синє або чорне вікно, а в його заголовку (верхня
смужка) є слово **Адміністратор** (або **Administrator**).

**Тепер перейдіть у папку проєкту.** Скопіюйте, вставте у вікно і натисніть Enter:

```powershell
cd C:\lessonsinshelter
```

**Як зрозуміти, що вийшло:** рядок у вікні тепер виглядає так:

```
PS C:\lessonsinshelter>
```

> ❗ Якщо з'явився червоний текст «Не удается найти путь» / «Cannot find path» — папку
> розпаковано не туди або названо інакше. Поверніться до кроку 2.

**Не закривайте це вікно** — воно знадобиться в кроках 4–7.

## Крок 4. Дозволити запуск скриптів

Windows за замовчуванням не дає запускати скрипти, а файли з інтернету вважає підозрілими.
Цей крок знімає обидва обмеження для нашого проєкту.

**Що зробити:** у тому самому вікні PowerShell вставте й натисніть Enter:

```powershell
Get-ChildItem -Recurse | Unblock-File
```

Потім вставте другу команду й натисніть Enter:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

Комп'ютер перепитає, чи ви впевнені. Надрукуйте літеру **`Y`** (англійська) і натисніть
**Enter**. (Якщо в підказці є варіант **`A`** — «Так для всіх» — можна натиснути його.)

**Як зрозуміти, що вийшло:** знову з'явився рядок `PS C:\lessonsinshelter>`, червоного тексту
немає.

## Крок 5. Завантажити дві програми

Для роботи потрібні дві безкоштовні програми: **MediaMTX** (роздає звук на телефони) і
**ffmpeg** (бере звук з мікрофона). Скрипт завантажить їх сам.

> Для цього кроку потрібен **інтернет**.

**Що зробити:**

```powershell
.\server\win\download-tools.ps1
```

**Що буде відбуватися:** з'явиться напис `Качаю mediamtx.exe ...`, потім `Качаю ffmpeg.exe ...`.
Разом це близько 140 МБ — може зайняти від 2 до 10 хвилин. Вгорі вікна може бігти смужка
завантаження. **Просто чекайте**, нічого не закривайте.

**Як зрозуміти, що вийшло:** зеленим написано

```
Готово: mediamtx.exe
Готово: ffmpeg.exe
Обидві програми лежать у C:\lessonsinshelter\server\bin
```

> ❗ Якщо червоним написано щось про з'єднання або «Невозможно соединиться» — перевірте, чи
> є інтернет, і запустіть ту саму команду ще раз. Вже завантажене скрипт пропустить.

## Крок 6. Відкрити доступ для телефонів

Windows має «захисну стіну» (фаєрвол), яка не пускає до комп'ютера чужі пристрої. Телефони
дітей для неї — чужі. Цей крок робить у стіні «дверцята» лише для нашої системи.

**Що зробити:**

```powershell
.\server\win\allow-firewall.ps1
```

**Як зрозуміти, що вийшло:** зеленим з'явилися чотири рядки, що починаються зі слова
`Відкрито:`.

> ❗ Якщо написано «Потрібні права адміністратора» — вікно відкрите звичайним способом.
> Закрийте його і відкрийте знову, як описано в кроці 3.

### Позначити мережу як «приватну»

Дверцята працюють лише в мережі, яку Windows вважає **приватною** (домашньою/робочою).
Перевірте це:

1. Підключіть комп'ютер до того Wi-Fi, до якого будуть підключатися телефони дітей.
2. Натисніть **Пуск** → **Параметри** (значок шестірні).
3. Відкрийте **Мережа й Інтернет**.
4. Натисніть **Властивості** біля вашої мережі (у Windows 10: **Wi-Fi** → клацнути по назві
   мережі).
5. У розділі **Профіль мережі** оберіть **Приватна**.

## Крок 7. Дізнатися назву мікрофона

Комп'ютеру треба точно сказати, з якого мікрофона брати звук. Для цього дізнаємось його
«офіційну» назву.

**Що зробити:**

1. Вставте мікрофон-петличку (або її приймач) в USB-роз'єм комп'ютера. Зачекайте 10 секунд.
2. У вікні PowerShell виконайте:

```powershell
.\server\win\list-devices.ps1
```

**Що з'явиться:** кілька рядків. Шукайте рядок, де в кінці написано **`(audio)`**. Наприклад:

```
[dshow @ 0000020f] "Мікрофон (USB Audio Device)" (audio)
```

Назва мікрофона — це те, що **між лапками**: `Мікрофон (USB Audio Device)`.

**Запишіть цю назву** — на папірець або в Блокнот. Точно, літера в літеру, **разом із
дужками**. Вона знадобиться щодня.

> Як скопіювати текст із вікна PowerShell: виділіть назву мишкою (затиснувши ліву кнопку)
> і натисніть **Enter** — текст скопійовано. Потім вставте його в Блокнот через **Ctrl + V**.

> ❗ Якщо рядків з `(audio)` кілька — вам потрібен той, де є слово **USB** або назва вашої
> петлички. «Мікрофон (Realtek...)» — зазвичай вбудований мікрофон ноутбука, він не підходить.
>
> ❗ Якщо рядка з вашою петличкою немає зовсім — витягніть її, вставте в інший USB-роз'єм
> і повторіть команду.


## Крок 8. Запустити сервер (вікно 1)

**Що зробити:**

1. Підключіть комп'ютер до шкільного Wi-Fi (того, до якого підключаться телефони).
2. Відкрийте PowerShell **від імені адміністратора** — точно як у кроці 3.
3. Вставте ці два рядки і натисніть Enter:

```powershell
cd C:\lessonsinshelter
.\server\win\start-server.ps1
```

4. Якщо вискочить віконце «Брандмауер Windows заблокував деякі функції» — поставте галочку
   **Приватні мережі** і натисніть **Дозволити доступ**.

**Як зрозуміти, що вийшло:** у вікні зеленим написано `Медіасервер працює`, а нижче —
**адреса для телефонів**, наприклад:

```
Сторінка для дітей:
   http://192.168.0.50:8080/
```

Нижче там же надруковано **список усіх класів із кодами** (`klas-5-1`, `klas-6` …) — код
свого класу знадобиться в кроці 9.

**Запишіть цю адресу** — її відкриватимуть діти. Вона зазвичай однакова щодня, але може
змінитися, якщо змінився Wi-Fi.

> ⚠️ **Це вікно має лишатися відкритим весь урок.** Його можна згорнути (кнопка `—` у
> правому верхньому куті), але не закривати хрестиком. Закрите вікно = немає звуку.
>
> Рядок `PS C:\lessonsinshelter>` тут **не з'явиться** — і так має бути: сервер працює,
> доки вікно відкрите.

---

## Крок 9. Увімкнути мікрофон (вікно 2)

**Що зробити:**

1. Перше вікно **не чіпайте**.
2. Відкрийте **ще одне** вікно PowerShell від імені адміністратора (як у кроці 3).
3. Скопіюйте команду нижче **в Блокнот** (не одразу в PowerShell):

```powershell
cd C:\lessonsinshelter
.\server\win\start-mic.ps1 -Device "Мікрофон (USB Audio Device)" -Channel klas-5-1 -Slow
```

4. У Блокноті замініть дві речі:
   - `Мікрофон (USB Audio Device)` → назва **вашого** мікрофона з кроку 7. Лапки навколо
     назви **залишаються**.
   - `klas-5-1` → код **вашого** класу з таблиці нижче.
5. Скопіюйте виправлену команду з Блокнота, вставте у **вікно 2** і натисніть Enter.

> 💡 Збережіть цей файл Блокнота на робочому столі (наприклад, `мікрофон.txt`). Завтра не
> доведеться нічого виправляти — просто скопіюєте звідти.

**Коди класів** (список можна змінити у файлі `web\channels.json`):

| Клас | Код | | Клас | Код |
|---|---|---|---|---|
| 5-1 | `klas-5-1` | | 8 | `klas-8` |
| 5-2 | `klas-5-2` | | 9-1 | `klas-9-1` |
| 6 | `klas-6` | | 9-2 | `klas-9-2` |
| 7-1 | `klas-7-1` | | 10 | `klas-10` |
| 7-2 | `klas-7-2` | | 11 | `klas-11` |

Слово `-Slow` у кінці не прибирайте: воно потрібне, щоб звук працював на айфонах.

**Як зрозуміти, що вийшло:** у вікні написано назву класу, мікрофона і **пряме посилання на
цей клас**, наприклад:

```
  Клас:     5-1   (Сектор 1)
  Мікрофон: Мікрофон (USB Audio Device)
  Канал:    klas-5-1

  Посилання саме на цей клас - його можна надіслати дітям:
     http://192.168.0.50:8080/listen.html?ch=klas-5-1
```

Після цього вікно «застигає» — **це нормально**, так воно і працює.

> ⚠️ **Це вікно також не закривати до кінця уроку.** Можна згорнути.
>
> ❗ Якщо з'явився жовтий напис «Каналу ... немає у web\channels.json» — ви помилились у
> коді класу. Закрийте вікно 2 і повторіть крок 9 з правильним кодом.
>
> ❗ Якщо з'явилося `Could not find audio only device` — назва мікрофона вписана неточно.
> Порівняйте з записаною в кроці 7 літера в літеру.

## Крок 10. Підключити телефони

**Що робить дитина:**

1. На телефоні підключається до **того самого Wi-Fi**, що й комп'ютер.
2. Якщо телефон пише «Мережа без доступу до Інтернету» — обирає **Залишатися підключеним**
   (або «Все одно використовувати»).
3. Відкриває браузер (Chrome, Safari) і в рядку адреси вводить адресу з кроку 8, наприклад
   `http://192.168.0.50:8080/`.
4. Натискає на свій клас у списку.
5. Натискає велику кнопку **▶ Слухати** і вдягає навушники.

> 💡 Щоб не диктувати адресу кожному — відкрийте на комп'ютері файл
> `C:\lessonsinshelter\web\print.html`, роздрукуйте (**Ctrl + P**) і повісьте на стіну.
> Або надішліть у чат класу пряме посилання з кроку 9 — дитина одразу потрапить на свій урок.

## Перевірка перед першим уроком

Зробіть це **за день до уроку**, а не при дітях. Перевіряйте саме в такому порядку:

- [ ] **На самому комп'ютері.** Відкрийте браузер і введіть адресу з кроку 8. Має відкритися
      список класів. Якщо тут не працює — справа не в телефонах, а в кроках 8–9.
- [ ] **На одному Android-телефоні.** Підключіть до Wi-Fi, відкрийте адресу, натисніть
      «Слухати», говоріть у петличку. Ви маєте чути себе в навушниках.
- [ ] **На одному iPhone** — обов'язково. Якщо тиша — натисніть «Спробувати повільний
      режим» і зачекайте 5–10 секунд.
- [ ] **Тільки після цього** — на цілому класі.

## Як усе вимкнути

1. Клацніть у **вікно 2** (мікрофон) і натисніть **Ctrl + C**. Потім закрийте вікно хрестиком.
2. Клацніть у **вікно 1** (сервер) і натисніть **Ctrl + C**. Зачекайте, доки з'явиться
   `Зупиняю медіасервер...`, потім закрийте вікно.

> Якщо просто закрити вікна хрестиком — нічого страшного, але наступного разу сервер може
> поскаржитись, що «порт зайнятий». Що тоді робити — у таблиці нижче.

## Що може піти не так

| Що бачите | Що робити |
|---|---|
| Червоний текст «выполнение сценариев отключено» / «виконання сценаріїв вимкнено» | Не зроблено крок 4. Виконайте його |
| «Не удается найти путь» / «Cannot find path» | Папка лежить не в `C:\lessonsinshelter`. Поверніться до кроку 2 |
| «Потрібні права адміністратора» або «Закрийте це вікно і відкрийте PowerShell через «Запуск від імені адміністратора»» | Вікно відкрите звичайним способом. Закрийте й відкрийте як у кроці 3 |
| `Порт 8554 уже зайнятий: mediamtx` | Сервер з минулого разу не вимкнувся. Під цим написом скрипт показує команду на кшталт `Stop-Process -Id 1234 -Force` — скопіюйте її, виконайте, потім знову запустіть крок 8 |
| Після «Зупинити - Ctrl+C» одразу з'являється `Python` і `Зупиняю медіасервер...` (буває на новому ноутбуці) | Це заглушка Microsoft Store замість справжнього Python. Оновіть папку проєкту до свіжої версії: скрипт сам її пропустить. Або встановіть Python з python.org (галочка «Add python.exe to PATH»), або вимкніть заглушку: Параметри → Програми → Додаткові параметри програм → Псевдоніми виконання програм → вимкнути `python.exe` і `python3.exe` |
| «Порт 8080 вже зайнятий» | Цей «вхід» зайняла інша програма. Виконайте `.\server\win\allow-firewall.ps1 -WebPort 8081`, потім `.\server\win\start-server.ps1 -WebPort 8081`. Адреса для дітей тоді закінчуватиметься на `:8081/` |
| На телефоні відкривається чужа сторінка, наприклад «Server is up and running» | Та сама причина, що й рядок вище — зробіть те саме |
| `Could not find audio only device` | Назва мікрофона вписана неточно. Повторіть крок 7 і скопіюйте назву разом із дужками |
| Телефон пише «Немає зв'язку з сервером» або сторінка не відкривається | 1) Телефон підключений до іншого Wi-Fi — перевірте назву мережі. 2) Не зроблено крок 6. 3) Мережа не «приватна» — див. кінець кроку 6. 4) Телефон у гостьовій мережі роутера — підключіть до основної |
| Сторінка відкривається, але звуку немає | Повторіть крок 6 (саме у вікні адміністратора). Перевірте, що вікно 2 відкрите і в ньому немає червоного тексту |
| На iPhone тиша | Натисніть на сторінці «Спробувати повільний режим» і зачекайте 5–10 секунд |
| Звук зник посеред уроку | Хай дитина оновить сторінку (потягнути сторінку вниз або кнопка ↻) і знову натисне «Слухати» |
| Звук обривається, коли гасне екран телефона | Попросіть дітей не блокувати екран — на деяких телефонах це зупиняє звук |
| Після 20–30 телефонів усе заїкається | Звичайний домашній роутер не тягне стільки підключень. Потрібна точка доступу офісного класу |
| Адреса в кроці 8 не показалась, написано «мережеву адресу визначити не вдалось» | Комп'ютер не підключений до Wi-Fi. Підключіть і запустіть крок 8 знову |

## Шпаргалка на щодень

Можна роздрукувати й покласти біля комп'ютера.

```
 1. Підключити комп'ютер до шкільного Wi-Fi.
 2. Вставити петличку в USB.

 3. ВІКНО 1:  Пуск → набрати powershell → права кнопка
              → «Запуск від імені адміністратора» → Так
              Вставити і натиснути Enter:

      cd C:\lessonsinshelter
      .\server\win\start-server.ps1

              Записати адресу для дітей. Вікно НЕ закривати.

 4. ВІКНО 2:  ще раз відкрити PowerShell так само.
              Вставити команду з файлу «мікрофон.txt» і натиснути Enter.
              Вікно НЕ закривати.

 5. Перевірити звук на своєму телефоні.
 6. Діти: Wi-Fi → адреса → свій клас → ▶ Слухати.

 Після уроку: у кожному вікні Ctrl + C, потім закрити.
```
