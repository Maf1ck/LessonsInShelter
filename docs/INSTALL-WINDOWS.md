# Встановлення на чистий Windows

Покрокова інструкція для комп'ютера, на якому немає нічого, крім щойно встановленої Windows 10
або 11. Нічого «програмістського» ставити не доведеться: ані Python, ані Node, ані Git —
усе потрібне або вже є в Windows, або качається одним скриптом.

Разом це займає приблизно 20 хвилин, з яких більшість — очікування завантаження.

## Що знадобиться з заліза

| Що | Навіщо |
|---|---|
| Ноутбук або міні-ПК з Windows | на ньому працює сервер |
| USB-петличка або USB-звукова карта з мікрофоном | голос учителя |
| Wi-Fi роутер чи точка доступу | мережа, до якої підключаються телефони |
| Павербанк або ДБЖ | живлення, коли зникає світло |

Інтернет потрібен **лише на час встановлення**. Під час уроку ані сервер, ані телефони в
інтернеті не потребують.

## Крок 1. Покласти проєкт на комп'ютер

Найпростіше — без Git:

1. Відкрити сторінку проєкту на GitHub.
2. Зелена кнопка **Code** → **Download ZIP**.
3. Розпакувати, наприклад, у `C:\lessonsinshelter`.

Далі в інструкції ця папка називається «папка проєкту».

## Крок 2. Дозволити запуск скриптів

Windows за замовчуванням не запускає скрипти PowerShell, а файли, завантажені з інтернету,
позначає як «небезпечні». Це знімається двома командами.

Відкрийте **PowerShell**: кнопка «Пуск» → наберіть `powershell` → **Windows PowerShell**.

```powershell
cd C:\lessonsinshelter
Get-ChildItem -Recurse | Unblock-File
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

На запит підтвердження натисніть `Y` і Enter. Це робиться один раз.

## Крок 3. Завантажити дві програми

```powershell
.\server\win\download-tools.ps1
```

Скрипт сам завантажить `mediamtx.exe` (медіасервер) і `ffmpeg.exe` (робота зі звуком) і покладе
їх у `server\bin`. Разом це близько 140 МБ, тож кілька хвилин доведеться зачекати.

У репозиторії цих файлів немає навмисно: вони великі й у кожного своя версія під свою систему.

## Крок 4. Дізнатися назву мікрофона

Увімкніть петличку в USB і виконайте:

```powershell
.\server\win\list-devices.ps1
```

У списку знайдіть свій мікрофон і **скопіюйте назву цілком**, разом із дужками. Виглядає це
приблизно так:

```
"Мікрофон (USB Audio Device)" (audio)
```

## Крок 5. Відкрити порти у фаєрволі

Без цього телефони не побачать сервер, навіть підключені до того самого Wi-Fi.

Потрібен PowerShell **від імені адміністратора**: «Пуск» → правою кнопкою по **Windows
PowerShell** → **Запуск від імені адміністратора**.

```powershell
cd C:\lessonsinshelter
.\server\win\allow-firewall.ps1
```

Робиться один раз. Мережа, до якої підключені телефони, має бути позначена в Windows як
«приватна» — перевірити можна командою `Get-NetConnectionProfile`.

## Крок 6. Запустити сервер

У першому вікні PowerShell:

```powershell
cd C:\lessonsinshelter
.\server\win\start-server.ps1
```

Скрипт надрукує адреси, за якими телефони відкриють сторінку. **Це вікно має лишатися
відкритим** — щойно ви його закриєте, звук зникне.

Якщо на комп'ютері немає Python (а на чистій Windows його немає), сторінку роздає вбудований
вебсервер Windows, і тоді **це вікно теж має бути відкрите від імені адміністратора**. Скрипт
сам скаже про це і зупиниться, якщо прав не вистачає.

Якщо скрипт напише, що порт 8080 зайнятий, виберіть інший — див. «Що може піти не так».

## Крок 7. Увімкнути мікрофон

Відкрийте **друге** вікно PowerShell (перше не чіпайте):

```powershell
cd C:\lessonsinshelter
.\server\win\start-mic.ps1 -Device "Мікрофон (USB Audio Device)" -Channel klas-5-1 -Slow
```

Замість `Мікрофон (USB Audio Device)` підставте назву зі кроку 4. Ключ `-Slow` вмикає
резервний потік для айфонів — лишайте його завжди.

Це вікно теж має лишатися відкритим.

## Крок 8. Підключити телефони

1. Телефон підключається до того самого Wi-Fi, що й комп'ютер.
2. У браузері відкриває адресу, яку надрукував крок 6, наприклад `http://192.168.0.50:8080/`.
3. Обирає свій клас і натискає велику кнопку **▶ Слухати**.

Щоб не диктувати адресу кожному, роздрукуйте `web/print.html` і повісьте на стіну.

## Перевірка перед першим уроком

1. Відкрийте адресу на самому комп'ютері. Якщо тут не працює — справа не в телефонах.
2. Потім на одному телефоні Android і обов'язково на одному iPhone.
3. Тільки після цього — на цілому класі.

## Що може піти не так

| Ознака | Причина і що робити |
|---|---|
| Сторінка пише «Server is up and running» або щось чуже | Порт 8080 зайнятий іншою програмою (pgAdmin, Jenkins). Запустіть на іншому порту: `.\server\win\allow-firewall.ps1 -WebPort 8081` від адміністратора, потім `.\server\win\start-server.ps1 -WebPort 8081`, і давайте телефонам адресу з `:8081` |
| «Немає зв'язку з сервером» на телефоні | Телефон у чужій мережі, або не виконано крок 5 |
| Сторінка відкривається, але звуку немає | Правила фаєрвола не застосувались: сторінка йде по 8080, а звук по 8189/udp. Перезапустіть крок 5 саме від адміністратора |
| `Could not find audio only device` | Назва мікрофона скопійована не цілком. Візьміть її з кроку 4 разом із дужками |
| Скрипт не запускається, «виконання сценаріїв вимкнено» | Не зроблено крок 2 |
| `Порт 8554 уже зайнятий: mediamtx` | Медіасервер з попереднього запуску не закрився. Скрипт друкує готову команду з потрібним PID — виконайте її і запустіть знову |
| На iPhone тиша | Натисніть «Спробувати повільний режим». Перші кілька секунд він мовчить, поки сервер готує потік |
| Після 20–30 телефонів усе починає заїкатись | Домашній роутер не тягне стільки клієнтів, потрібна точка доступу офісного класу |

## Щоденний запуск

Після встановлення кроки 1–5 більше не потрібні. Щодня потрібні лише два вікна:

```powershell
# вікно 1
cd C:\lessonsinshelter
.\server\win\start-server.ps1

# вікно 2
cd C:\lessonsinshelter
.\server\win\start-mic.ps1 -Device "Мікрофон (USB Audio Device)" -Channel klas-5-1 -Slow
```
